
# Footprinting and Network Scanning

## About This Repository

This repository contains hands-on cybersecurity practicals covering footprinting, reconnaissance and network scanning using Kali Linux tools and Zenmap.

## Practical Modules

### 1. Footprinting and Reconnaissance

Performed using six Kali Linux tools:

- WHOIS – Domain registration information
- WhatWeb – Website technology identification
- Nslookup – DNS lookup
- cURL – HTTP response header analysis
- WAFW00F – Web Application Firewall detection
- DNSRecon – DNS enumeration

### 2. Network Scanning using Zenmap

Performed on my own local network using Zenmap (Nmap GUI).

Activities included:

- Identifying local IP configuration and LAN subnet
- Discovering live hosts
- Counting active hosts
- Reviewing IP and MAC address information
- Visualising network topology

**Result:** 5 live hosts discovered.
